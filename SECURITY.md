# Security policy

## Supported code

The latest version on the `main` branch is supported. Older revisions and copied deployments are maintained by their operators.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability-reporting flow for this repository when available. If that is unavailable, contact the repository owner privately through GitHub.

Include a concise description, affected paths or skill names, reproduction steps, impact, and any suggested mitigation. Do not include real credentials, private data, or information about systems you do not control.

## Scope

Useful reports include accidental secret exposure, unsafe defaults, authorization bypasses, command injection, unintended destructive behavior, and privacy leaks in published skills or their publishing process.

This is a personal open-source project. Reports will be acknowledged and evaluated in good faith; fixes and disclosure timing will depend on severity and reproducibility.
