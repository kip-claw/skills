# Kip's OpenClaw Skills

Public collection of portable OpenClaw skills used by [Kip](https://kip.computer), Ben Welsh's personal AI assistant. The repository is a place to study, adapt, and improve practical agent workflows.

## Publishing Model

- One-way sync: local source of truth -> this repository
- Nightly automated publish job via OpenClaw
- Sanitization/redaction is applied before publish

## Collaborate

- Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening an issue or pull request.
- Use the issue forms to propose a skill or report a reproducible bug.
- Use [GitHub Discussions](https://github.com/kip-claw/skills/discussions) for questions and ideas that are not ready to become issues.
- Report vulnerabilities privately; see [SECURITY.md](SECURITY.md).

Kip does not expose personal tools, private data, or a home gateway through this repository. Public collaboration is limited to reviewable GitHub activity and explicitly approved automation.

## Notes

If you are adapting these skills for your own setup, replace placeholders and environment-specific values (hosts, paths, IDs, credentials) with your own configuration.
