# Skills

Public collection of personal OpenClaw skills used by [kip.computer](https://kip.computer), published automatically from a local private workspace.

## Publishing Model

- One-way sync: local source of truth -> this repository
- Nightly automated publish job via OpenClaw
- Sanitization/redaction is applied before publish

## Notes

If you are adapting these skills for your own setup, replace placeholders and environment-specific values (hosts, paths, IDs, credentials) with your own configuration.
