Public collection of personal OpenClaw skills, published automatically from a local private workspace.

- `reading-list`
- `runs-log`

- `todo-archival`
- `tv-control`
- `voice-transcribe`

## Excluded From Public Publish

- Plugin skills (`browser-automation`, `wiki-maintainer`, `obsidian-vault-maintainer`)
- Email/calendar skills (`imap-smtp-email`, `caldav-calendar`)

## Publishing Model

- One-way sync: local source of truth -> this repository
- Nightly automated publish job via OpenClaw
- Sanitization/redaction is applied before publish

## Notes

If you are adapting these skills for your own setup, replace placeholders and environment-specific values (hosts, paths, IDs, credentials) with your own configuration.
